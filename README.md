Hi, My name is **Prudvi**.

This is **Chit-Chat**, a chatting Application designed for real-time communication with a sleek and minimal interface.

## ✨ Features

- **Real-time Messaging**
- **User Authentication**
- **Online Status**
- **Interactive UI**
- **Sound Notifications**
- **Secure by Design**
- **Email Notifications**

## 🚀 Setup

If you are thinking about setup, it is as easy as "npm install":

1. Run the command:
   ```bash
   npm install
   ```
2. The terminal will ask for some credentials. 
3. Paste them, and your `.env` file will be generated automatically.
4. Setup is complete!

If you are looking for what credentials are needed, go to [Wiki > Credentials Needed For ENV](https://github.com/PRUDVINATH16/chit-chat/wiki/Credentials-Needed-For-ENV).
