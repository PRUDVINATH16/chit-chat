# 🏗️ Architecture in 60 Seconds

Chit-Chat is built on a modern MERN stack with real-time capabilities.

### 💻 Frontend (The Face)
- **React**: Component-based UI.
- **Zustand**: Clean and minimal state management.
- **Tailwind CSS + DaisyUI**: Beautiful, responsive styling.
- **Socket.io-client**: Connects to the server for live updates.

### ⚙️ Backend (The Brain)
- **Node.js & Express**: Fast and scalable server logic.
- **Socket.io**: Handles real-time message broadcasting.
- **JWT**: Secure, stateless authentication.
- **Arcjet**: Middleware for bot protection and rate limiting.

### 🗄️ Database (The Memory)
- **MongoDB**: Flexible NoSQL document storage.
- **Mongoose**: Elegant object modeling for Node.js.

### ☁️ Services
- **Cloudinary**: Efficient image hosting and transformations.
- **Nodemailer**: Transactional email delivery.
