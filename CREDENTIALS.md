# 🔑 Credentials Needed For ENV

To get this project running, you need to set up several API keys. Follow the links below to quickly get your credentials:

### 1. MongoDB URI
Store your data in the cloud.
- **Get it here:** [MongoDB Atlas](https://www.mongodb.com/cloud/atlas/register)

### 2. Cloudinary (Media Storage)
Used for uploading and hosting profile pictures.
- **Get it here:** [Cloudinary Dashboard](https://cloudinary.com/console)
- *You will need: Cloud Name, API Key, and API Secret.*

### 3. Arcjet (Security)
Protects your app from bots and rate-limits requests.
- **Get it here:** [Arcjet Dashboard](https://app.arcjet.com/)

### 4. Nodemailer (Email)
Used to send welcome emails. If using Gmail, you need an **App Password**.
- **Get it here:** [Google App Passwords](https://myaccount.google.com/apppasswords)

### 5. JWT Secret
Any random string of your choice to secure user sessions.

---
*Once you have these, the setup script will help you generate your `.env` file.*
